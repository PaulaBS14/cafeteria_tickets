# Cafetería Tickets
## Descripción
Este proyecto es un programa sencillo en Java para gestionar las ventas de una cafetería. Permite crear clientes, camareros y diferentes tipos de productos, añadir productos a un ticket, calcular el total de la compra y aplicar descuentos.

## Requisitos

- Java JDK instalado.
- Un entorno de desarrollo compatible con Java, como IntelliJ IDEA.

## Compilación y ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Compilar el proyecto.
3. Ejecutar la clase `Main`.

## Funcionalidades

- Gestión de clientes y camareros.
- Creación de productos de comida y bebida.
- Creación de tickets de compra.
- Cálculo del precio total del ticket.
- Aplicación de descuentos.

## Estructura del proyecto

- `src/`: contiene las clases Java del programa.
- `test/`: destinada a las pruebas del proyecto.
- `docs/`: contiene la documentación del proyecto.
- `README.md`: información general del proyecto.

## Instrucciones de uso

Al ejecutar el programa se crea un cliente, un camarero y varios productos de la cafetería. Los productos se añaden a un ticket, que muestra la información de la compra y calcula el precio total. También se aplica un descuento a uno de los productos.
